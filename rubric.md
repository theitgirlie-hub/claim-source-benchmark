# The Rubric

## Before You Begin

1.  Write down the claim exactly as written. Never paraphrase it. If it
    is dependent upon the previous text ("Under this model"), place the
    previous sentence in a separate context field.
2.  Write down the type of source (primary, review, news), date (or
    "undated") and mode of access (live or archive). This is metadata
    and is never scored.

## Definitions

1.  **Element:** One fact, figure, date, or cause-and-effect
    relationship within the claim. The qualifiers ("first," "full,"
    "thousands," "all") are not elements; they modify an element and are
    considered only for Scope.
2.  **Addressed:** The source refers to the element, even if it refers
    to it differently. An element that refers to an event that occurred
    later than the date of the source, or one referred to as having not
    yet occurred, is not addressed.
3.  **Stated:** The reader who accepts the source must necessarily
    accept the element. If the reader could question it, then the
    element is implied.
4.  **Independent sources:** Republished wire article counts as one
    source.

## Stage 3: Verdict

         Total Verdict
  ------------ ----------------------------------
         **6** **Supported**
    **3 to 5** **Partly Supported**
    **2 to 1** **Compatible but not confirmed**

> **Override:** In cases where the source does not indicate any of the
> elements of the claim explicitly, or changes the basic meaning of the
> claim or refers to less than half of the claim's elements, then the
> claim cannot be referred to as either "Partly Supported" or
> "Supported", regardless of how many points it scores.

## Several Sources

1.  Apply the process to each source individually and document the
    verdict from each one.
2.  In determining the overall verdict, combine elements from
    independent, understandable, relevant sources. An element is
    considered to be discussed or mentioned by the source that first
    discusses or mentions the element, regardless of whether others have
    also done so. Scope scores the combination only once.
3.  In case the sources contradict themselves regarding an element, the
    overall verdict will be **Contradicted**, flagged as **"sources
    conflict."**

## Also Note

1.  **True according to other sources?** Yes, No, or Unknown, with the
    source cited. This is distinct from the decision.
2.  **Notes on evidence:** Found: \[element\] (section/page).
    Unaddressed: \[element\]. Search terms used: \[terms\].
3.  **Alerts:** potential conflict, conflicting sources, undated source,
    partial source, exact copy (circular citation possible), and
    borderline (2, 3, or 5 total).
